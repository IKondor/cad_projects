# starter-cube

Шаблонный проект монорепо: куб с ребром 2 м.

Нужен для двух вещей — проверить, что окружение живое (CadQuery считает,
экспорт пишется, вьюер подключается), и служить болванкой для новых проектов.

```bash
uv run python projects/starter-cube/model.py
```

Ожидаемый вывод: объём 8 м³, два файла в `out/`.

Структура `model.py` — рекомендуемый скелет: параметры отдельным блоком,
геометрия в `build()`, побочные эффекты (экспорт, просмотр) только
под `if __name__ == "__main__"`.
