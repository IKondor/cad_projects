# Квартира — базовая CAD-сцена

Это не проект мебели, а общий контекст для всех следующих проектов: в нём
заданы пол, стены, двери и окна квартиры. Мебель следует проектировать и
располагать в той же системе координат — тогда шкаф, кухня или тумба окажутся
на плане сразу в правильном месте.

```bash
uv run python projects/home/model.py
```

В `out/` появятся:

- `apartment-shell.step` — точная геометрия стен для CAD;
- `apartment-shell.stl` — оболочка для Blender и другого рендера;
- `plan.png` — контрольный вид сверху.

## Координаты

Начало `(0, 0, 0)` — левый нижний угол **основной** части квартиры на плане.
`X` направлена вправо, `Y` — к верхней стороне плана, `Z` — вверх от чистого
пола. Все значения в миллиметрах.

Опорные точки помещений находятся в `layout.py`. Пример для будущего скрипта:

```python
from projects.home.layout import place_at

cabinet = build_cabinet()
cabinet = place_at(cabinet, "bedroom_south_wall", offset=(600, 100, 0))
```

## Точность

Размеры в плане (общий габарит 5.94 × 6.70 м и размеры комнат) перенесены в
модель. Высота потолка 2700 мм, толщины стен, высоты подоконников и точные
границы проёмов пока являются рабочими допущениями — они собраны в верхнем
блоке `model.py`. Перед изготовлением мебели их нужно проверить лазерной
рулеткой и изменить только там.

Исходные файлы находятся в `data/`: `22.08.2026.glb` — 3D-скан для визуальной
сверки, `image.png` — поэтажный план, по которому построена оболочка.
